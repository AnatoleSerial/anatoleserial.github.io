Factions are nothing new in TTRPGs.
- Generic advice: https://slyflourish.com/build_a_faction_list.html
- Lancer-specific: https://gordianblade.com/supercharge-your-lancer-campaign-with-faction-rosters/

Chief advantage is that it simplifies creating multiple encounters across a story / campaign.

BASIC METHOD:
1. Write down THREE Narrative Keywords that describe the faction.
2. Select Core Faction Classes. One per Role. Based on the keywords, choose a second Class per Role when appropriate. I like having one or two single-class roles for minor factions, with major factions having even three-class roles.
3. Select a Preferred Grunt Class. If you ever need to have Grunts for this Faction, this will be your go-to.
4. (Optional) Select a list of preferred Templates. Something that makes sense. You won't deploy *all* your NPCs with these templates, but it will inform you of the kind of strategies that you want to follow with these guys.
5. (Optional) Select some optional features per NPC class. This is not required to plan in advance, as you can do this before deploying them for the encounter
6. (Optional) Give each Faction Class some emblematic name.

Whenever you start a story, have at least 3 factions related to the state of the narrative: the 3 groups your PCs are most likely to encounter.
